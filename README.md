# Большая перемена здоровья | Воронеж — прототип сайта

Статический прототип главной страницы межведомственного проекта «Большая перемена здоровья» (Воронежская область, с 2024 года).

## Страницы
- `index.html` — главная: краткие выдержки трёх блоков со ссылками «Подробнее».
- `about.html` — О программе: направления, цели, этапы скрининга, хронология, график 2026/2027.
- `news.html` — Новости БПЗ: все публикации с фильтром по рубрикам.
- `analytics.html` — Аналитика: KPI, охват по возрастам, группы риска, факторы риска.
- `request.html` — заявка родителей «Пригласить БПЗ в школу» (без данных о здоровье ребёнка).
- `login.html`, `admin.html` — вход и панель координатора: заявки по школам со статусами, сводка, новости, смена пароля.
- `politika.html` — шаблон политики обработки персональных данных (заполняет оператор).

## Сервер и демо-режим
На хостинге с PHP 8.1+ и MySQL заявки сохраняются в базу и приходят письмом координатору — см. **[DEPLOY.md](DEPLOY.md)**.
Без PHP (GitHub Pages, открытие файла) сайт работает в демо-режиме: данные только в браузере, вход `admin` / `demo`.

## Запуск
Открыть `index.html` в браузере (сборка не нужна, демо-режим).

С бэкендом локально: создать `api/config.php` с `'db_dsn' => 'sqlite:' . __DIR__ . '/data/local.sqlite'`, запустить `php -S localhost:8000` и открыть http://localhost:8000/api/setup.php.

Опубликовано через GitHub Pages (ветка `main`, корень): https://dmiazdimaz-ctrl.github.io/Bolhaia_peremena_zdoroviia/

## Что заменить перед запуском
- Промежуточные этапы хронологии — уточнить у координаторов.
- Цифры аналитики — демо-данные в `app.js` (`AGES`, `RISK`, `FACTORS`). Новости (`NEWS`) — реальные публикации со ссылками.

## Файлы
- `styles.css` — стили (цвета из логотипа)
- `app.js` — данные и отрисовка новостей/диаграмм
- `store.js` — слой данных: API или демо-режим; `admin.js` — вход и панель координатора; `request.js` — заявка родителей
- `api/` — PHP-бэкенд (заявки, вход, новости), настройки в `api/config.php`
- `assets/` — логотип
