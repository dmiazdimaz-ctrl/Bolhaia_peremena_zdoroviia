# Большая перемена здоровья | Воронеж — прототип сайта

Статический прототип главной страницы программы профилактики школьной миопии.

## Структура главной
1. **О программе** — описание, цели, задачи, хронология проекта, график скрининга 2026/2027.
2. **Новости БПЗ** — карточки с фильтром по рубрикам.
3. **Аналитика** — KPI, охват по возрастам, группы риска, частота факторов риска.

## Запуск
Открыть `index.html` в браузере (сборка не нужна).

## Что заменить перед запуском
- Даты этапов хронологии — заглушки.
- Новости и цифры аналитики — демо-данные в `app.js` (массивы `NEWS`, `AGES`, `RISK`, `FACTORS`).

## Файлы
- `index.html` — разметка
- `styles.css` — стили (цвета из логотипа)
- `app.js` — данные и отрисовка новостей/диаграмм
- `assets/` — логотип
